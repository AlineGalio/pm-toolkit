# Definition of Done (DoD)

A story is done only when all items are true.

- [ ] Code reviewed and merged to the main branch
- [ ] Acceptance criteria verified, one by one
- [ ] Unit and integration tests written and passing
- [ ] Pipeline green, including static analysis, dependency scan and secret scan
- [ ] No new critical or high vulnerabilities
- [ ] Deployed to staging and smoke tested
- [ ] Logging, monitoring and alerts updated when behavior changed
- [ ] Documentation updated (README, API spec, runbook, ADR if a decision was made)
- [ ] Rollback path known
- [ ] Product Owner accepted the result in review
