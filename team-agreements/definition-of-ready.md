# `team-agreements/definition-of-ready.md`

## Definition of Ready (DoR)

A story enters a sprint only when all items are true.

- [ ] Story follows "As a / I want / so that" and has a clear business value
- [ ] Acceptance criteria are written in Given/When/Then and are testable
- [ ] Scope and out-of-scope are stated
- [ ] Dependencies are identified, with owners and dates
- [ ] UX, API contracts or data needs are available when relevant
- [ ] Security and compliance impact was assessed
- [ ] Team estimated it and it fits in one sprint (otherwise, split it)
- [ ] Test approach is agreed (unit, integration, manual)
- [ ] Product Owner confirmed priority
